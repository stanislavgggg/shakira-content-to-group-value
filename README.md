# tg-news-poster

Автопостинг новостей в 4 канала по расписанию, с отбором только топовых материалов.
Переписано из `news_multi_en.py`: сбор RSS, отсев колонок и сверка чисел оттуда,
всё остальное новое.

## Что изменилось против старого скрипта

| Было | Стало |
|---|---|
| Один `CHANNEL` в коде | 4 канала в `config.py`, каждый со своим языком и тайзоной |
| Английский текст | Перевод на LT / LV / BG / HR по каналу |
| `random.shuffle` — берём что попало | Двухступенчатый отбор, ниже порога не постим вообще |
| Запуск руками | Демон с расписанием на Railway |
| Числа не из источника — только предупреждение | Пост пропускается |
| Дедуп один на всех | Свой `seen` на канал |

## Отбор «только топовые»

1. **Жёсткий отсев** — колонки, `/opinion/`, `/sponsored/`, короткие огрызки, старше 36 ч, уже постили.
2. **Эвристика** — вес источника (`feeds.py: TIER`) + сигналы реальной новости (сделки, лицензии, суммы, трансферы) − штраф за `best/top 10/guide/bonus code` − штраф за возраст. Отбирает 14 кандидатов.
3. **Оценка моделью** — все 14 одним запросом, балл 0–100 с явной шкалой. Ниже `MIN_SCORE` (по умолчанию 72) — **слот пропускается молча**. Лучше тишина, чем проходняк.
4. **Сверка чисел** — если в переводе появилась цифра, которой нет в источнике, пост не уходит. Запятую как десятичный разделитель понимает (`4.2 million` → `4,2 mln` проходит).

## Расписание

12 слотов в сутки, по 1 посту. Время **локальное для канала**:

```
09:00  sports     — утро, спорт
13:00  industry   — обед, индустрия
19:00  casino     — вечер, казино
```

Меняется в `config.py` → `schedule`. Можно разное по каналам, можно добавить `gaming`.
`python poster.py --plan` покажет итоговую сетку.

Если контейнер перезапустился и слот пропущен, он досылается в течение 55 минут.
Дважды за день один слот не выстрелит — маркеры в `fired.json`.

## Деплой на Railway

1. Залить папку в репозиторий, в Railway → New → Deploy from GitHub repo.
2. **Volume**: Railway → Variables → Add Volume, mount path `/data`. Без него после каждого редеплоя бот забудет, что уже постил, и зальёт повторы.
3. Variables:
   ```
   TG_BOT_TOKEN=...
   ANTHROPIC_API_KEY=sk-ant-...
   STATE_DIR=/data
   MIN_SCORE=72
   ```
4. Бота — админом во все 4 канала с правом постинга. На старте делается `getChat` по каждому, при отказе сервис падает с понятным сообщением.
5. Сервис поднимается как `worker` (`python poster.py --serve`), HTTP-порт не нужен.

Первый прогон лучше с `DRY_RUN=1` — всё считает и печатает в логи, в Telegram не шлёт.

## Локально

```bash
pip install -r requirements.txt
export TG_BOT_TOKEN=... ANTHROPIC_API_KEY=sk-ant-...

python poster.py --check                       # живость фидов
python poster.py --plan                        # сетка расписания
python poster.py --preview luckyguru sports    # прогон без отправки
python poster.py --once balkanjackpot casino   # один слот с отправкой
```

## Что нужно вписать руками

- **`promo` в `config.py`** — пусто у всех четырёх. Без ссылки кнопка под постом не рисуется. Подставь трекинговые ссылки каналов; в старом скрипте стоял общий `gggroup-forever.com`, но для этих каналов нужны свои.
- **Проверить фиды** — `--check`. В старом наборе спортивных источников было всего два, я добавила ESPN и Sky Sports; если какой-то отдаёт `DEAD`, убери из `feeds.py`.
